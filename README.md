# PIVNIK для Эвотора 1.0.11

Тестовая диагностическая сборка из [PR #277](https://github.com/GrafTrahula666/pivnik-bonus-app/pull/277), исходный commit `f2405f6137f36ef557317b09c58f73bd31e4ef68`. Изменения пока не смержены в main; работа связи на реальной кассе после этого обновления ещё не подтверждена.

Установите `pivnik-evotor-1.0.11.apk` **поверх нашей подписанной 1.0.10**, обычным обновлением. Удалять приложение и очищать его данные не требуется: пакет, постоянная подпись и зашифрованное хранилище настроек сохранены. Эта подпись не совместима с исходными 1.0.8 и 1.0.9, подписанными одноразовыми debug-ключами.

После обновления откройте PIVNIK → «Проверить связь без ключа». Дождитесь результата, проверка двух адресов может занять до 90 секунд. Новая версия ждёт ответ шлюза до 30 секунд и показывает длительность, TLS issuer и полученные ошибки шлюза. Увеличение ожидания не является доказательством устранения причины сетевого сбоя.

Только после подтверждения связи сохраните ключ кассы и проверьте его отдельно. Для клиента: добавьте товары в Эвоторе, откройте PIVNIK, отсканируйте QR и вернитесь к продаже после подтверждения. Реальное начисление требует привязки к тому же UUID чека и импорта закрытого документа. **Списание бонусов пока не реализовано.**

Проверены 602 теста Node, 36 JVM-тестов, повторная materialize с побайтовой сверкой, npm check, Android release compile, manifest, apksigner v1/v2/v3 и zipalign. APK подписан восстановленным постоянным ключом; сертификат побайтово совпадает по SHA-256 с нашей опубликованной 1.0.10. Хеш APK находится в SHA256SUMS, сведения о сборке — в build-info.json.
