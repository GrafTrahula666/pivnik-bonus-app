# PIVNIK для Эвотора 1.0.10

**Тестовая сборка из draft PR #277; на реальной кассе ещё не проверена.** Владелец отдельно разрешил выпуск и подготовку разовой переустановки. Проверенная подпись не означает, что касса уже подключена. Списание бонусов пока не реализовано.

1. Сначала убедитесь, что ключ кассы `pvpos_…` доступен для повторного ввода.
2. Удалите именно **PIVNIK для Эвотора**: 1.0.8/1.0.9 подписаны другими ключами. Его локальные настройки сотрутся.
3. Установите `pivnik-evotor-1.0.10.apk` поддерживаемым на вашей кассе способом через прежний канал установки/распространения. GitHub не доставляет APK на кассу автоматически.
4. Откройте PIVNIK → Настройки → **Проверить связь без ключа**. Вводить `pvpos_…` для этого не нужно. При ошибке сохраните точный текст и время нажатия.
5. После успешной проверки связи сохраните ключ кассы и проверьте его отдельно. Для сканирования клиента добавьте товары в продажу, откройте PIVNIK, отсканируйте QR и вернитесь к продаже после подтверждения.

Начисление проверяется по одному закрытому чеку и его облачному UUID. Сетевой таймаут, доступ Эвотора, начисление и возвраты требуют аппаратной проверки. Новая постоянная подпись сохранена вне Git; более новые версии с ней смогут обновляться поверх 1.0.10.

APK собран в Android CI из `a8f08eeb700b450be08609a26781600ad4b1443e`, run `38707728700`. Постоянная подпись добавлена локально после восстановления приватной резервной копии. `signature.txt`, `SHA256SUMS` и `build-info.json` содержат результаты проверки.
