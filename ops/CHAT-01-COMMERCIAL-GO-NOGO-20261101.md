## 1. Явные критерии готовности, без выдуманного процента

Только независимые статусы: **IMPLEMENTED** = исходник в конкретном SHA; **MERGED** = в main; **DEPLOYED** = подтверждён SHA и deployment ID конкретного сервиса; **ENABLED** = подтверждено действующее feature flag/entitlement для конкретного tenant; **LIVE_E2E_PASS** = реально выполнен разрешённый сценарий с доказательствами; **EXTERNAL_APPROVED** = согласована текущая редакция договора/лицензии/провайдера. UNKNOWN не равно true, реальный 0 не равно «нет данных», отдельный зелёный PR CI не равен зелёному main release, HTTP health не равен проверенному сквозному функционалу.

**GO** только если ниже все P0 по независимому стороннему владельцу и его store/venue имеют доказуемые PASS, а нужные P1 MVP-функции принимаются владельцем. **HOLD** — временная остановка интеграции до внешнего доказательства. **NO-GO** — текущий коммерческий результат, поскольку несколько обязательных P0 и релизный gate не закрыты.
