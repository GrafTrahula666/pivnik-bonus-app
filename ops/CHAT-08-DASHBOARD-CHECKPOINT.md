## Сверка KPI по коду, без реальных значений

| Экран / термин | Источник и формула | Вердикт |
| --- | --- | --- |
| Эвотор: **Выручка** | `pos/analytics.js`: `netCents = salesCents - returnsCents` | Отличается от суммы продаж **до** возвратов; не дубликат |
| Эвотор: **Операций** | `saleDocuments + returnDocuments` | Учитывает продажи и возвраты, не совпадает с числом чеков |
| Эвотор: **Подтверждённые чеки продажи** | `receiptCount`; если часть чеков неизвестна, значение `null` | Не эквивалентно документам операций; оставлено в раскрываемых подробностях |
| Эвотор: **Средний чек** | `salesCents / receiptCount` при полной известности числа чеков | Не взаимозаменяем с `netCents / operations` |
| Эвотор: **Клиенты приложения** | `summarizePos(documents.filter(d => d.clientId))` | Подмножество «Все продажи кассы», а не дополнительный поток дохода |
| Приложение: **Сумма операций приложения** | `transactions.cash_paid_cents` для завершённых `accrue/redeem` | Не является подтверждённой общей кассовой выручкой |
| Приложение: **Записей о покупках** | `checkCount`: завершённые `accrue/redeem` с `check_amount_cents > 0` | Не равно всем завершённым операциям |
| Приложение: **Операции** | `operationCount`: завершённые строки журнала | Отдельная метрика; сейчас используется в сравнении |
| Приложение: **Клиентов всего** | Текущий snapshot членов заведения | Не историческая активная аудитория |
| Приложение: **Совершали операции** | Уникальные клиенты с завершёнными операциями за период | Не равно «Клиентов всего» |

**Итог #71:** на проверенных KPI **не доказано ни одного тождественного смыслового дубля**, который можно удалить безопасно. Поэтому удалений или переименований в runtime **нет**. Наличие похожих слов («продажи», «чеки», «операции», «выручка») само по себе не доказательство равенства формул. Визуальное уплотнение, приоритет 3–5 KPI и раскрытие второстепенных относятся к отдельным #72/#78, не подменяют аудит #71.
