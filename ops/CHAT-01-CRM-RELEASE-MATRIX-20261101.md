## Evidence vocabulary

These are **four independent checks**, not one release flag:

- **Implemented:** the cited function/code path exists on the pinned `main`. `PARTIAL` means a deliberately restricted diagnostic or incomplete customer journey; `UNMOUNTED` is tested code that has no active call path; `NO` means the intended SaaS user path is absent, not that every related helper is absent.
- **Merged:** the cited source is in pinned `main`. `YES` is version-control evidence only; it does not prove migrations, provider approval or runtime flags.
- **Deployed:** actual Railway deployment **revision** and whether the identified product has confirmed enablement. `SRC` means the Admin source version containing the relevant code is reported as deployed, **not** that the feature is enabled, reachable or verified with live data. `UNKNOWN` means no reliable production activation/config/DB proof. This document never upgrades `SRC` to "active".
- **Live E2E:** `NOT VERIFIED` means no authenticated real independent tenant, approved Evotor account/store, paid license, real POS reconciliation and real mobile business flow were exercised in *this* run. Source tests, local fixtures, main deploy status and public health do **not** count as live E2E.
