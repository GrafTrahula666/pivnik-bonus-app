# V14.4 — исправление QR-сканера

- Telegram WebApp SDK теперь загружается через `defer` перед `app.js`, без гонки загрузки.
- Перед каждым запуском сканера мост Telegram перечитывается заново.
- Проверяется поддержка Bot API 6.4+.
- Камера закрывается только после успешной проверки QR сервером.
- Убрано двойное закрытие сканера.
- При ошибке камеры автоматически предлагается ввод короткого кода.
- Обновлены версии клиентских файлов для сброса кэша Telegram.
