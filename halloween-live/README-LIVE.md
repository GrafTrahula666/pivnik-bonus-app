# Рабочий запуск 31 октября 2026

Сервис использует существующую базу PIVNIK и отдельную схему `halloween_live`.
Финальные адреса и результаты проверки записываются в передаваемую владельцу
инструкцию. Старый Railway-сервис с `npm run demo` использует вымышленные данные.

Сборка из корня репозитория: `docker build -f halloween-live/Dockerfile .`.
Команда контейнера: `node src/server.js`; `LIVE_MODE=live`, выделенный
`LIVE_DATABASE_URL`, `LIVE_PUBLIC_ORIGIN`, `LIVE_ACCOUNTS_JSON` обязательны.
У сервиса нет миграций в startup и автоматического перехода на демо.

Телефон открывается личной ссылкой `/scanner#access=...`, выпущенной владельцу.
Токен передаётся серверу один раз для создания HttpOnly сессии роли scanner;
из адресной строки он удаляется, в журнал розыгрыша не попадает. Владелец может
отозвать ссылки заменой `LIVE_SCANNER_ACCESS_TOKEN`; уже выданные сессии живут
до истечения 12 часов либо смены учётных данных scanner. Пульт требует пароль.

30 октября после резервного копирования базы вручную подготовлены миграции
001/002 и ограниченная роль из 003. По указанию владельца срок закрытия
изменён на 30.10.2026 23:59 МСК. Приложение не может изменять этот срок.
Сама жеребьёвка при подготовке не выполняется.

Операции бонусов, депозитов, рамок и складского списания не должны имитироваться
SQL-записями. До подключения существующих авторизованных API выдача таких
наград остаётся ручной, с отдельной сверкой в основной системе.
