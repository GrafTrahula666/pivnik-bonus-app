# Обновление «ПИВНИК»: VK Mini App

Архив подготовлен для загрузки в корень репозитория `GrafTrahula666/pivnik-bonus-app` **с заменой** `package.json` и `.env.example`.

## Состав

- `universal-server.js` — общий шлюз Telegram + VK;
- `vk-platform.js` — VK Bridge и адаптация существующего интерфейса;
- `package.json` — переключает запуск Railway на общий шлюз;
- `.env.example` — полный список переменных;
- `legal/` — политика и правила;
- `VK-SETUP.md` — точная настройка кабинета VK;
- `VK-APP-CARD.md` — готовые тексты для карточки и модерации.

## После загрузки

Railway автоматически выполнит деплой. До добавления `VK_APP_ID` и `VK_APP_SECRET` Telegram-версия продолжит работать, а VK-вход будет возвращать понятную ошибку конфигурации.
